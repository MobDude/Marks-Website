Real-Time Fire Fighting Drone Simulator

A distributed system simulation of autonomous firefighting drones operating in real time. The system models coordination, communication, and physical behavior across multiple independent processes.

The architecture is composed of three core components:

  • Scheduler: Central coordinator responsible for task assignment, state tracking, and synchronization
  • Drone Subsystem: Simulates drone behavior including movement, resource management, and faults
  • Fire Incident Subsystem: Generates and manages fire events over simulated time

The GUI its showing drones fires, and status.

Each component runs as an independent process and communicates via UDP, while the Scheduler acts as a synchronized monitor using Java threads.

Key Features

  • Distributed Architecture: Independent processes communicating over UDP
  • Thread-Safe Scheduler: Monitor-based synchronization using wait/notify
  • Drone Simulation: State machine, physics-based movement, and resource constraints (water and battery)
  • Real-Time GUI: Live visualization of drones, fires, and system state
  • Event Simulation: Time-driven fire generation from CSV input
  • Fault Handling: Detection and recovery mechanisms for drone failures
  • Logging & Metrics: Simulation logging with performance analysis (response time, completion time, utilization)

Colour Guesser

A clone of an existing website (ColorGuesser) where you guess a colour based on its name. It pulls from a database of over 5000 colours and changes daily. All users get the same colours and can only play once per day.

Current Features

  • Display Chosen colour in name
  • Shows actual compared to the guessed color
  • Shows which out of five rounds user is on
  • 5000+ colours
  • Colours rotate daily and are the same for everyone
  • Can share results by copying results to clipboard

Discord Movie Bot

A Discord bot that helps friends organize movie nights together. Features include viewing the movie list, adding and removing movies from the list with fuzzy search, getting data and posters from external api, and automatically scheduling discord events based on defined criteria, such as length of movie or days of week.

The first page of the movie list showing the next movie.

The second page showing the next 5 movies.

Current Features

  • Search for movies on TMDB and pull data including posters
  • Display a list of movies on a paginated discord embed
  • Add movies by searching database by name and optionally year
  • Dropdown functionality for multiple results
  • Remove movies by entering a movie's name
  • Display movie posters on embed
  • Automatically create, schedule, and delete discord events
