# Marks Personal Website

Welcome to my personal website! This site is a personal project for fun, but it also showcases my projects, hobbies, and skills, while also serving as I practice web development.

---

## Features

- About Me section with hobbies and interests
- Projects section showcasing GitHub projects
- Contact page with social media links
- Movies page with movies I have watched rated and reveiwed.
- Movies page has filters and sorting options
- Adventures page where I can share adventure stories.
- Music page showcasing some songs along with their genres and some notes. Uses Spotify embeds to allow playing the songs.
- Photo Gallery 
- Multiple selectable themes
